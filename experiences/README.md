# Expériences

Configurations versionnées d'expériences ESP
(population initiale, paramètres économiques, graine de simulation).

## Profils de développement

Les fichiers préfixés `developpement-` sont des **VALEURS DE DÉMONSTRATION** :

- NON PRÉENREGISTRÉES ;
- NON DESTINÉES AUX FUTURES EXPÉRIENCES SCIENTIFIQUES ;
- elles ne prétendent pas déterminer les futurs bons paramètres ESP.

Exemple actuel : `developpement-population-v01.json`.

Les montants monétaires sont des chaînes décimales entières en micro-USDC
(`"10000000"` = 10 USDC).
